PlantStory Support

Need help, found a bug, or have an idea? Contact the developer directly or open an issue on GitHub.

Ask for help

Email zicodeng@gmail.com for support, or use GitHub to report a reproducible bug or suggest an improvement.

Email support Open a GitHub issue

What to include

These details help diagnose the problem more quickly:

  • PlantStory app version and build number
  • iOS or iPadOS version
  • iPhone or iPad model
  • Steps to reproduce the issue
  • What you expected and what happened instead

Protect your private information

Never include an API key, private photo, or PlantStory backup file in an email or public GitHub issue. You can remove personal details from screenshots before sharing them.

Privacy

PlantStory stores your garden data locally on your device. Read the PlantStory Privacy Policy to learn how local data, manual backups, and optional features are handled.
